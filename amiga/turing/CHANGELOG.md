# Changelog

## 0.1.0-beta.1

First packaged release of the native Amiga Turing 3.5-inch USB monitor.

- Direct Poseidon USB transport for the verified Rev-A display.
- Live ZZ9000 temperature, Chip/Fast memory and sampled 68K CPU load.
- CPU clock estimate via optional identify.library; nominal ARM clock labelled separately.
- Mounted-drive capacity/usage and active IPv4 address.
- Kickstart/Workbench versions and Workbench resolution/depth.
- Recorded A4000TX hardware profile, including Kicksmash32 and ZZ9000AX.
- Aggregate memory and mounted-disk totals, excluding RAM Disk from storage totals.
- Ten-second pages alternating orange/blue and blue/white text.
- LCD-style Workbench icon, single-instance launch and optional nonblocking boot startup.
- Missing-device startup skips quietly; reconnect and relaunch the icon to resume.
- Workbench install scripts, optional autostart and exact framebuffer capture mode.

ARM utilization is unavailable. Hardware profile entries are recorded facts,
not an automatic inventory. CPU load and clock figures are estimates.
